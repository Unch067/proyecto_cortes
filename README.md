# Grupo 3 - Plan de Corte y Aprovechamiento de Retales

Aplicación en Streamlit para optimizar el corte unidimensional de perfiles y tuberías en obra, aprovechando el inventario de retales y minimizando la compra de tubos nuevos.

## Instalación y Ejecución

1. Instalar Python 3.9 o superior.
2. Abrir la terminal en la carpeta del proyecto.
3. Ejecutar:

```bash
pip install -r requirements.txt
streamlit run app.py
